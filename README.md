
# Assignment #9 - Giphy API

## Project Description
This project is an interactive website that uses JavaScript and the Giphy API to fetch and display GIFs.

## Features
- Fetches GIFs from the Giphy API
- Displays 8 GIFs when the button is clicked
- Allows users to search for GIFs by keyword
- Displays GIFs in a responsive Bootstrap grid
- Handles errors when API requests fail

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Giphy API

## How It Works
1. Enter a keyword in the search box.
2. Click the Fetch a GIF button.
3. JavaScript sends a request to the Giphy API.
4. The API returns GIF image URLs.
5. The GIFs appear on the webpage.

## Extra Credit
The search feature allows users to find GIFs using their own keywords instead of a fixed search term.
